# 📌 Overview

This repository contains complete **Terraform automation projects and Infrastructure as Code (IaC) examples** designed for DevOps engineers and cloud automation learning.

The project demonstrates how Terraform is used to provision, manage, and automate cloud infrastructure using declarative configuration files.

It includes:

- Terraform Basics
- AWS Infrastructure Provisioning
- EC2 Automation
- VPC Setup
- Security Groups
- S3 Buckets
- Variables & Outputs
- Modules
- Remote State Management
- Terraform Best Practices
- DevOps Infrastructure Automation

Terraform is an open-source Infrastructure as Code (IaC) tool created by HashiCorp for building, changing, and versioning infrastructure safely and efficiently. ([github.com](https://github.com/hashicorp/terraform?utm_source=chatgpt.com))

# 🌍 What is Terraform?

Terraform is an Infrastructure as Code (IaC) tool that allows developers and DevOps engineers to define cloud infrastructure using configuration files.

Terraform supports multiple cloud providers including:

- AWS
- Azure
- Google Cloud
- Kubernetes
- Docker
- GitHub

Terraform enables automated and repeatable infrastructure provisioning workflows. ([github.com](https://github.com/hashicorp/terraform?utm_source=chatgpt.com))
